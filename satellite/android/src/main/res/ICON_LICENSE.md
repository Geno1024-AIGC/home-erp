# Launcher icon — emoji artwork

The launcher icon reuses the **house** emoji (**U+1F3E0**, `1F3E0.png`) from
[OpenMoji](https://openmoji.org/) — the open‑source emoji and icon project —
under the **CC BY‑SA 4.0** license. The glyph is composed on a solid deep‑blue
(`#1F2C66`) background for use as a launcher icon (legacy PNGs + adaptive-icon
foreground).
